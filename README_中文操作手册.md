# 银发历史文化街区语义数字孪生仿真实验室 3.5.0

## 启动

1. 完整解压交付 ZIP。
2. 双击 `双击启动应用.vbs`。
3. 浏览器右上角应显示 `v3.5.0`。
4. 使用结束后双击 `关闭应用.bat`。

## 推荐流程：只知道研究地点

1. 进入“场景重建”，选择“我只知道研究地点”。
2. 输入地点名称，例如“成都宽窄巷子”或“苏州平江路”。
3. 选择地点数据来源、搜索结果与研究半径。
4. 点击“生成地点空间骨架”。
5. 在主画布和对象复核表中确认、修改或删除对象。
6. 点击“生成三维数字孪生与碰撞体”。
7. 进入对象模块调整建筑、道路、台阶、导视牌和设施。
8. 进入Agent、任务与仿真模块运行500 Agent实验。

### 地点数据来源

- **本地离线地点库**：无需网络和API Key，适合快速跑通流程。
- **高德地图 Web 服务**：填写高德Web服务Key，获取国内地点、周边POI和最多3条步行路线。
- **百度地图 Web 服务**：填写百度Web服务AK，获取国内地点、周边POI和最多3条步行路线。
- **OpenStreetMap**：无需Key，但依赖国外公开服务可访问。

地图Key只通过当前请求发送给本机服务，不写入浏览器存储或项目文件。高德和百度用于地点选择、POI与步行路线；系统会将GCJ-02坐标转换为WGS84，再从OpenStreetMap读取真实建筑多边形与道路中心线。

## 国内地图三维样式

高德或百度地点模式新增三种重建样式：

- **融合模式（默认）**：采用VoxCity式语义分层，叠加map3d式建筑和道路挤出；适合Agent仿真与空间干预。
- **map3d建筑与道路挤出**：使用简洁的建筑体量、轮廓边线和高度表达，适合规划分析。
- **VoxCity语义体素风格**：建筑和植被使用量化体素外观，突出建筑、交通、树冠、POI和街具图层。

地图重建只使用真实建筑轮廓，不再沿路线生成代理建筑。目标地点没有可用的OSM建筑数据或网络请求失败时，程序加载内置的真实OSM多边形示范街区，并明确标注该场景不代表目标地点。

“进入世界”现在同时支持国内地图语义场景、离线模板、GeoJSON、现场轨迹、普通可编辑模型和Marble场景；点击后会清除当前变换手柄，并定位到道路或人行道上的人视高度。
## 其他入口

- **我有地点照片**：上传普通照片或360°全景图，识别建筑、道路、台阶、导视牌、座椅与障碍物。照片用于补充外观和设施，不再承担凭单图猜测完整街区布局的任务。
- **我可以去现场拍摄**：导入手机GPX/CSV轨迹；现场视频会提取代表帧，照片和视频帧进入现有语义复核流程。
- **我有专业地图资料**：直接导入GeoJSON，自动转为米制语义对象和三维场景。
- **可选高级来源**：Marble、兼容多模态API和已有3DGS/GLB文件均保留，但不再是主流程的必要条件。

## 仿真数据对应关系

- `poi`设施目标进入设施可达性任务。
- `sign`导视牌进入导视可见性和信息密度计算。
- `bench`座椅进入休息行为计算。
- 建筑、树木、护栏等生成碰撞与障碍数据。
- 道路、人行道、广场和台阶生成可行走表面。
- 车辆继续参与Agent与车辆、车辆与车辆之间的动态避碰。

## 研究边界

地点模式以公开地图和人工复核为基础，强调道路、建筑和设施的语义与位置关系。它不是测绘级成果。正式论文实验应使用现场照片、关键宽度、台阶和指示牌位置进行复核，并在报告中记录数据来源和误差。

## 离线地点库

当本机无法访问国外公开地图服务时，程序会优先使用内置历史街区研究模板。当前包含宽窄巷子、平江路、夫子庙、三坊七巷、南锣鼓巷、丽江古城、大理古城、乌镇、周庄和田子坊。输入这些地点名称后不需要联网即可搜索和生成。

离线模板用于建立可编辑、可碰撞和可仿真的研究空间，不是测绘级1:1复刻。正式实验应继续上传照片、现场轨迹并复核道路宽度、台阶、导视牌和设施位置。
